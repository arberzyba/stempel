Files for trying Stempel and for the screenshots in the main README.

| File | What it is |
|---|---|
| `rechnung-mit-fehler.xml` | The XML from the ZUGFeRD example `EN16931_Einfach` (FeRD, via the [Mustang project](https://github.com/ZUGFeRD/mustangproject)), with one change: the total with VAT (`GrandTotalAmount`) is 529.78 instead of 529.87, so the check reports rule BR-CO-15. The FeRD usage notice at the top of the file is unchanged. |
